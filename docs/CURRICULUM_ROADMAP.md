# Curriculum roadmap — NeVeRhOOd Academy

## Course structure

Each **original Academy course** includes a stated audience, prerequisites, competency outcomes, lessons, runnable exercises, project/capstone, practice assessments, rubrics, verified achievement record, and a learner-readable correction path. Accessibility and mobile-friendly navigation are mandatory.

## Learning tracks

| Track | Example original capstones | External study resources |
|---|---|---|
| Computing foundations | Build and troubleshoot a small workstation, document hardware and OS diagnostics | Original provider links |
| Systems programming | C++ and Rust memory-safe/native interoperability, unit tests, profiling | Official C++/Rust docs |
| AI agents and tools | Implement a permissioned tool registry, bounded agent task, verifiable receipts | Model/provider documentation |
| LLM and model development | Tokenizer compatibility audit, checkpoint manifest, local evaluation | Official ML courses |
| Cloud and distributed computing | Durable queue + worker leasing + restart recovery | Vendor docs and open courses |
| Automation and integration | Protobuf and FlatBuffers protocol benchmarking with JSON baseline | Official serialization docs |
| Software engineering | Full-stack portfolio project with GitHub Actions and accessibility | Provider curriculum |
| Applied security | Threat model, secret handling, least privilege and audit log | Vendor security docs |
| Digital media engineering | Original short-film shot planner and reproducible media pipeline | Licensed creator resources |

## Captain AEGIS integration

Captain is proposed as a study assistant for concepts, code explanations, debugging and original practice quizzes. It should respond with source references and clear uncertainty. It is not authorized to sit exams for students or act as credential issuer.

Enable this only after the real Captain model loads on independent, approved serving infrastructure and endpoint reliability, privacy and cost are measured.

## Evidence-based learning

The Academy should require real assignments and projects. Downloading a certificate, clicking a course link or reading a resource does not automatically award completion.

## Academic level

Labels such as "graduate-level topics" describe content complexity, not academic degree credit. A research project or graduate-inspired pathway offered here does not confer any university degree.
